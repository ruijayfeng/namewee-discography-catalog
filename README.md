# 黄明志主要专辑目录与整理记录

本仓库保存公开的曲目元数据、官方来源链接、曲序、缺失清单和本地整理验证记录。**不包含音频、视频、封面图片或登录凭据，也不提供整套音频的下载附件。**

整理快照日期：2026-11-03。范围为 14 张专辑／EP，已整理记录共 166 个音轨文件，来自 161 个不同官方视频：154 个主目录曲目、12 个附加版本。

## 音源与标签说明

本地整理时使用 yt-dlp 的 `bestaudio` 选择最高可用源流，保留原始编码：165 个 Opus、1 个 AAC，没有再次压缩音频。标签包含曲名、艺人、专辑艺人、专辑、日期、曲序、碟号、流派及来源说明，并嵌入专辑封面。

音源来自官方 MV／歌词视频，保留原始对白、片头片尾，可能与唱片版的时长及剪辑不同；这些记录不代表无损唱片母带。

每个成功文件在本地均核对过标签、封面、音频流一致性和完整解码。仓库内的验证结果是整理时的记录；它不表示仓库包含音频，或链接将始终可用。

## 校验目录或本地文件

Python 3.11+，无需第三方依赖：

```bash
python3 scripts/validate_catalog.py
```

如持有此次整理的本地文件，可额外核对文件 SHA-256：

```bash
python3 scripts/validate_catalog.py --library /path/to/local/library
```

脚本只检查元数据和已存在的本地文件，不执行下载，也不读取浏览器登录信息。
